DOCUMENTACIÓN TÉCNICA Y ARQUITECTURA

Sistema de Gestión de Información de Estudiantes Inactivos

Institución: Universidad Antonio Nariño
Sede: Pereira, Risaralda
Framework: Django 5.0+ / Python 3.11+

1. Resumen Ejecutivo y Propósito

El presente documento define los lineamientos estandarizados de desarrollo, arquitectura de software, modelo de datos y guía de despliegue para el Sistema de Gestión de Información de Estudiantes Inactivos de la Universidad Antonio Nariño (UAN) Sede Pereira.

El sistema soluciona la dispersión documental y facilita la trazabilidad de los estudiantes que interrumpieron su proceso formativo, ofreciendo una herramienta web centralizada, segura y escalable para la toma de decisiones directivas y el seguimiento de retención estudiantil.

2. Arquitectura del Sistema

La aplicación está construida bajo el patrón arquitectónico MVT (Model-View-Template) nativo de Django, priorizando la separación de responsabilidades y la seguridad de los datos.

Capa de Presentación (Templates & Static)

  • Interfaz adaptativa (Responsive) optimizada para navegadores modernos.
  • Uso de componentes modulables y plantillas base heredables.
  • Protección explícita contra vulnerabilidades XSS y CSRF.

Capa de Negocio y Datos (Views & Models)

  • Vistas basadas en clases (CBV) y funciones optimizadas.
  • ORM de Django para consultas eficientes y seguras.
  • Transiciones de estado controladas para expedientes de estudiantes.
